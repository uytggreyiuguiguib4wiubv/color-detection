Real-Time Color Detection using OpenCV

This project uses your computer's webcam to detect and label multiple colors in real-time using OpenCV and NumPy. The script identifies common colors such as red, green, blue, yellow, orange, purple, and more — drawing bounding boxes and labels around detected regions.

🧠 Features

Real-time webcam color detection

Supports a wide range of colors (12 total)

Uses HSV color space for robust detection under variable lighting

Draws bounding boxes and labels with corresponding colors

Noise reduction using morphological operations

Adjustable detection thresholds for fine-tuning
